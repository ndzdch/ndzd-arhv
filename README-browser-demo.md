# Браузерное демо · 0.6.3

Демо находится в `browser-demo/`. Оно собрано из текущих исходников приложения 0.6.3. Стили, значки и настоящий Canvas-редактор используются без переработки дизайна.

Запуск из папки проекта:

```sh
node scripts/build-browser-demo.mjs
node scripts/serve-browser-demo.mjs
```

Открыть http://127.0.0.1:8767. Если Node отсутствует в PATH, на этом Mac доступен `node`.

Выберите JPEG или папку целиком через исходное меню загрузки либо перетащите файлы или папку в область загрузки. Фотографии и правки хранятся только в памяти вкладки; перезагрузка очищает демонстрацию. Удаление скрывает кадр только внутри демо. Сохранения на диск и скачивания фотографий нет. Сетевые соединения для обработки и отправки данных запрещены CSP (`connect-src 'none'`); сервер только отдаёт статические файлы и принимает GET/HEAD.

Mac-приложение, его каталог и сборки в `release/` не изменены. Для повторной сборки демо из актуальных исходников:

```sh
node scripts/build-browser-demo.mjs
```

Скрипт копирует текущий `src/` и ресурсы, затем применяет адаптацию только внутри `browser-demo/`. Если macOS выгрузила ресурс в iCloud, допускается локальный ресурс установленного приложения с теми же размером и временем изменения. При несовпадении сборка прекращается.

Проверено: 26 тестов модели/редактора; в браузере — импорт двух JPEG, поворот с изменением Canvas 1000×667 → 667×1000, отмена, кадрирование 667×667, удаление и очистка после перезагрузки. CSS, редактор, модель редактирования и рендерер совпадают с исходниками байт в байт.
